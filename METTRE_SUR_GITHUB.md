# Mettre ce projet sur ton GitHub (Berodak)

Tout est prêt. Comme pour CYBER-SECU, le plus simple :

## GitHub Desktop (déjà installé et connecté)
1. Décompresse ce dossier `CPP-EPITECH` là où tu veux (ex :
   `C:\Users\berodak\OneDrive\Documents\CPP-EPITECH`).
2. GitHub Desktop → **File → Add local repository** → choisis ce dossier →
   **create a repository** → nom : `cpp-academie-tek2` → **Create repository**.
3. Clique **Publish repository** (décoche « Keep this code private » si tu le
   veux public).

## En ligne (sans rien installer)
- <https://github.com/new> → nom `cpp-academie-tek2` → **Create** →
  « uploading an existing file » → glisse le contenu du dossier → **Commit**.

## Ou dis-moi de le faire
Quand ton PC sera rallumé et connecté, je peux reprendre la main (comme pour
CYBER-SECU) et tout publier moi-même. Dis-moi juste « pousse le projet C++ ».

Astuce : active ensuite **GitHub Pages** (Settings → Pages → Branch main) pour
une adresse web publique de la plateforme.
