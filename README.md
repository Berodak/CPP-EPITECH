# 💻 C++ Académie — Prépa Tek2 (Epitech)

Plateforme pour apprendre le **C++ de zéro**, en français, et arriver prêt à la
**deuxième année d'Epitech** : la Piscine C++ et les projets objet (NanoTekSpice,
Arcade, Plazza, Zappy…).

Cours expliqués simplement, quiz, **défis « devine la sortie du programme »**
(chaque sortie est vérifiée au compilateur `g++`), progression en XP et rangs.

## 🚀 Démarrer

Double-clique sur **`index.html`** : tout se charge dans le navigateur, sans
rien installer, hors ligne. (La version développée, en plusieurs fichiers, est
dans `plateforme/`.)

> La **version en ligne** (lien claude.ai) ajoute la synchronisation de ta
> progression et le **Prof IA** qui te met sur la piste sans donner la réponse.

## 📚 Programme — 11 modules, 11 défis

| # | Module |
|---|--------|
| 0 | Démarrage (Epitech, la Piscine, la méthode) |
| 1 | Compiler et exécuter (terminal, g++, erreurs) |
| 2 | Variables et types (int, double, char, string, cin/cout) |
| 3 | Conditions et boucles (if/switch, while/for) |
| 4 | Les fonctions (paramètres, return, portée) |
| 5 | Pointeurs et références (le cœur du C++) |
| 6 | Tableaux, string et vector |
| 7 | La POO : classes et objets |
| 8 | Héritage et polymorphisme |
| 9 | Les outils du Tek2 (Makefile, gdb, valgrind, norme, git) |
| 10 | Les projets du Tek2 & ton plan |
